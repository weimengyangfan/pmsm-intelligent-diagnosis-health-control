# 本次公开范围

源代码目录针对本项目的R4主线组织；历史完整RAR仍作为比赛归档保留。公开仓库不包含厂商标注Confidential的文件、工具二进制、硬件位流、个人凭据及运行中的临时会话目录。

实验evidence.json只进行了确定性的gzip压缩；解压内容与原始文件逐字节一致。status.json、action.json保留原始记录，软件和离线复核的结果与实际硬件实验分别陈述。

models/training_export中的脚本为历史恢复版本，现存源模型与现场哈希、最终F4固件及厂商时序问题在docs/reproduction.md中记录；公开说明不将这些核对事项写成已经解决。
